校务智理 v1.092 前端交互与视觉优化包

本次改动：
1. 扩展横向抓取拖动：制度分类、通知分类、知识库分类、超级课表日期/周次条、课表横向区域、文档字体控制等。拖动超过阈值才会抑制点击，普通点击不受影响；移动端仍可自然纵向滑动。
2. 隐藏横向滚动条（包括热门提问），保留滚动和抓取拖动，不再显示黑色滚动条。
3. 重构数据统计任务完成率区域：圆环与右侧指标采用 minmax(0,...) 的稳定网格，所有子项限制最小宽度，窄屏自动切换为纵向排列，避免重叠/卡住。
4. 优化桌面登录页：增加层次、柔和背景和玻璃质感表单卡片。
5. 优化移动登录页：蓝色顶部弧面中心上移、纵向半径加长；欢迎标题、说明和表单间距统一；用户名/姓名/密码输入统一为圆润胶囊，消除用户名框突兀的白色块。
6. 统一静态资源版本号和 Service Worker 缓存版本为 1.092。

部署：覆盖网站原有 index.html、style.css、app.js、sw.js。保留 config.js、android-bridge.js、后端 Worker、D1 数据和其余静态资源。部署后刷新页面；如仍是旧样式，清除站点缓存/Service Worker 后重新打开。

本包只修改前端布局、样式和横向拖动交互，不更改 API 地址、认证逻辑、业务数据和后端接口。
